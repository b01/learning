# Netplan

Is a network configuration abstraction renderer. Which means it is a utility for
network configuration on a Linux system.

You write descriptive network configuration in YAML.

NOTE: YAML is popular in 2026 for writing configurations. We have not given up
on JSON, but its to symbolly (has to many special characters that some peple
don't like, so we use YAML for humans an machines and JSON mainly for machines).

See the [Netplan website] for more information.
