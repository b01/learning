# Install ECR Credential Provider

You'll need to build the [ecr-credential-provider] application yourself.

1. Install Go:

   ```shell
   GO_VER="1.26.1"
   curl -LO https://go.dev/dl/go${GO_VER}.linux-amd64.tar.gz
   sudo tar -C /usr/local -xzf go${GO_VER}.linux-amd64.tar.gz --strip-components=1
   export GOPATH=/home/ubuntu
   export PATH="${PATH}:/home/ubuntu/bin"
   export CGO_ENABLED=0
   ```
2. Clone and build the `ecr-credential-provider` repository:

   ```shell
   sudo apt install -y make
   git clone https://github.com/kubernetes/cloud-provider-aws.git
   cd cloud-provider-aws
   git checkout -b tag-v1.37.0 v1.37.0
   make ecr-credential-provider
   ./ecr-credential-provider --version
   ```

   NOTE: If you cannot connect. Then download the source to your local machine.
   Then upload to the S3 proxy bucket, then download to your node.

3. Move the binary to:

   ```shell
   sudo cp ./ecr-credential-provider /usr/local/bin
   ```
4. Test it works:

   ```shell
   mkdir ~/.aws
   cat <<TXT | tee ~/.aws/config
   [default]
   use_dualstack_endpoint = true
   TXT
   echo '{"apiVersion": "credentialprovider.kubelet.k8s.io/v1","image": "602401143452.dkr.ecr.us-west-2.amazonaws.com/amazon-k8s-cni-init","kind":"CredentialProviderRequest"}' | /usr/local/bin/ecr-credential-provider get
   echo '{"apiVersion": "credentialprovider.kubelet.k8s.io/v1","image": "602401143452.dkr-ecr.us-west-2.on.aws/amazon-k8s-cni-init","kind":"CredentialProviderRequest"}' | /usr/local/bin/ecr-credential-provider get
   echo '{"apiVersion": "credentialprovider.kubelet.k8s.io/v1","image": "602401143452.dkr-ecr.us-east-2.on.aws/amazon-k8s-cni-init:v1.23.0","kind":"CredentialProviderRequest"}' | /usr/local/bin/ecr-credential-provider get
   ```
   NOTE: If it hangs, then you'll likely need to allow IPv4 internet access.
   See [Fix Internet Access for IPv4].
5. Make a configuration from the sample [credential-provider-config.yaml] file
   on control-plane-01.
   This is passed into the kubeadm init config to let the `kubelet` know
   how to use AWS Credential Provider.

   ```shell
   cat ~/samples/credential-provider-config.yaml \
     | sudo tee /var/lib/kubelet/credential-provider-config.yaml
   ```
6. Copy that file to the worker nodes:

   ```shell
   scp ~/cloud-provider-aws/ecr-credential-provider worker-01:~/
   scp ~/cloud-provider-aws/ecr-credential-provider worker-02:~/
   scp ~/samples/credential-provider-config.yaml worker-01:~/
   scp ~/samples/credential-provider-config.yaml worker-02:~/
   ```
   NOTE: Go onto each worker node and move that file into the `/var/lib/kubelet`
   directory.
