# Definitions

* Address space - in computing, and address space defines a range of discrete
addresses, each of which may correspond to a network host, a peripheral device,
a disk sector, physical memory location, a virtual memory location; or another
logical or physical entity.

* IANA - Internet Address Numbers Authority, is a global organization that
oversees IP address allocation, domain name root zones, and internet protocol
parameters. It is operated by ICANN.

* Private network - is a computer network that uses a private address space of
IP addresses. Commonly used for LANs in residential, office, and enterprise
environments. Both IPv4 and IPv6 define private address ranges. Anyone may use
these addresses without approval from regional or local Internet registries. IP
packets originating from or addressed to a private IP address may not be routed
through the public Internet.

* Subnet -

* Private IPv6 addresses - The concept of private networks has been extended to
IPv6. The address fc00::/7 is reserved by IANA for unique local addresses
(ULAs). They are unicast addresses. The first block defined is `fd00::/8`,
designed for /48 routing blocks, for which user may create multiple subnets.

* Unicast address - a one-to-one transmission from one point in a network to
another point; that is one sender and one receiver, each identified by a network
address.
