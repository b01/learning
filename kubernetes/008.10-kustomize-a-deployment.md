# kustomize A Deployment

## Get Started

1. Make a directory

   ```shell
    mkdir -p kustom-deployment/base && cd kustom-deployment/base
   ```
2. Generate a deployment manifest and kustomize manifest:

   ```shell
   kubectl create deployment --image=nginx --replicas=2 \
     acme --dry-run=client -o yaml | tee deployment.yaml
   kubectl create kustomize --dry-run=client -o yaml | tee kustomization.yaml
   ```
