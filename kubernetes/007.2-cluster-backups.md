# Cluster Backups

We're going to perform a series of backups that will safeguard our new cluster.
Technically these should be scheduled and automated. But this is our practice
cluster, so they can be performed right before we attempt to perform a task
that will alter the cluster.

## Backup Cluster Certificates

```shell
sudo tar -czvf cluster-cert-backup.tar.gz /etc/kubernetes/pki
```

It's enough to back up `/etc/kubernetes/pki/ca.crt` and
`/etc/kubernetes/pki/ca.key`, from these you can regenerate the rest. But its
also just as easy to back up the entire `/etc/kubernetes/pki` directory.

Not just place these archive in a safe place. We're just going to dump them in
the home directory of the VM user since this is our practice cluster.

## Backup etcd

1. Install `etcdctl` to the `control-plane-01` node. See [etcd Releases]

   ```shell
   ETCD_VER=v3.6.11
   DOWNLOAD_URL=https://github.com/etcd-io/etcd/releases/download
   
   rm -f /tmp/etcd-${ETCD_VER}-linux-amd64.tar.gz
   rm -rf /tmp/etcd-download-test && mkdir -p /tmp/etcd-download-test
   
   curl -L ${DOWNLOAD_URL}/${ETCD_VER}/etcd-${ETCD_VER}-linux-amd64.tar.gz -o /tmp/etcd-${ETCD_VER}-linux-amd64.tar.gz
   tar xzvf /tmp/etcd-${ETCD_VER}-linux-amd64.tar.gz -C /tmp/etcd-download-test --strip-components=1 --no-same-owner
   rm -f /tmp/etcd-${ETCD_VER}-linux-amd64.tar.gz
   sudo install -m 755 /tmp/etcd-download-test/etcdctl /usr/local/bin
   ```
2. Test you can connect:
   ```shell
   sudo etcdctl \
     --endpoints=https://[2000:192:168:56::11]:2379 \
     --cacert=/etc/kubernetes/pki/etcd/ca.crt \
     --cert=/etc/kubernetes/pki/etcd/server.crt \
     --key=/etc/kubernetes/pki/etcd/server.key \
     get / --prefix --keys-only --limit=10
   ```
3. Backup etcd database (replace the IP with the control-plane IP):
   ```shell
   mkdir -p ~/.backups
   sudo etcdctl \
     --endpoints=https://[2000:192:168:56::11]:2379 \
     --cacert=/etc/kubernetes/pki/etcd/ca.crt \
     --cert=/etc/kubernetes/pki/etcd/server.crt \
     --key=/etc/kubernetes/pki/etcd/server.key \
     snapshot save ./backups/etc-backup-$(date +%F).db
   ```
