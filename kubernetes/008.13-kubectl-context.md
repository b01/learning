# kubectl Context

1. See which contexts are available in a `kubeconfg`.

   ```shell
   kubectl config get-contexts --kubeconfig /vagrant/exercises/kubeconfig \
       --no-headers
   ```
2. Get the name of the current context.

   ```shell
   kubectl config current-context
   ```
3. Write the client-certificate of user `account-0027` base64-decoded.

   ```shell
   kubectl config view --raw -o jsonpath="{.users[0].user.client-certificate-data}" \
       | base64 -d
   ```
   Explanation:
   We use `kubectl config view --raw` to view the raw data in the kubeconfig.
   Then use the `-o jsonpath` option to drill down to the exact user data that
   we want. We figure out which index the user is at by looking at the
   kubeconfig, then count how many `-` down the user is; know that index
   starts at 0. To drill down to the field we want we then chain the field with
   a period leading up to the field we want. Then we pipe the output to the
   `base64 -d` utility, then pipe it again to the `openssl` utility and further
   decode it with the `x509` sub command and use options `-text -noout` to output
   text without echoing the encoded certificate.
