## kubectl Context

Extract the following information out of kubeconfig file
`/vagrant/exercises/kubeconfig `:

1. Write all kubeconfig context names into `/tmp/answers/contexts`, one per
   line.
2. Write the name of the current context into `/tmp/answers/current-context`.
3. Write the client-certificate of user `account-0027` base64-decoded into
   `/tmp/answers/account-0027.crt`.
