# Deployment with Gateway API

1. Make a namespace `gateway`

   ```shell
   kubectl create namespace gateway
   ```
2. Make a few apps along with services that expose them that will later have
3. traffic pass through a gateway.

   ```shell
   cat <<TXT | tee gateway-test-deployment.yaml | k apply -f -
   apiVersion: apps/v1
   kind: Deployment
   metadata:
     labels:
       app: web
     name: web
     namespace: gateway
   spec:
     replicas: 2
     selector:
       matchLabels:
         app: web
     template:
       metadata:
         labels:
           app: web
       spec:
         containers:
         - image: nginx
           name: nginx
           volumeMounts:
           - name: html
             mountPath: /usr/share/nginx/html
         volumes:
         - name: html
           configMap:
             name: web-deployment
   ---
   apiVersion: apps/v1
   kind: Deployment
   metadata:
     labels:
       app: api
     name: api
     namespace: gateway
   spec:
     replicas: 2
     selector:
       matchLabels:
         app: api
     template:
       metadata:
         labels:
           app: api
       spec:
         containers:
         - image: nginx
           name: nginx
           volumeMounts:
           - name: html
             mountPath: /usr/share/nginx/html
         volumes:
         - name: html
           configMap:
             name: api-deployment
   ---
   apiVersion: v1
   kind: ConfigMap
   metadata:
     name: web-deployment
     namespace: gateway
   data:
     index.html: Web Site
     status.html: Web is healthy
   ---
   apiVersion: v1
   kind: ConfigMap
   metadata:
     name: api-deployment
     namespace: gateway
   data:
     index.html: REST API
     status.html: Api is healthy
   TXT
   ```
4. Make services to expose the deployments.
   ```shell
   cat <<TXT | tee gateway-test-svc.yaml | k apply -f -
   apiVersion: v1
   kind: Service
   metadata:
     labels:
       app: web-svc
     name: web-svc
     namespace: gateway
   spec:
     ports:
     - port: 8080
       protocol: TCP
       targetPort: 80
     selector:
       app: web
   ---
   apiVersion: v1
   kind: Service
   metadata:
     labels:
       app: api-svc
     name: api-svc
     namespace: gateway
   spec:
     ports:
     - port: 8080
       protocol: TCP
       targetPort: 80
     selector:
       app: api
   TXT
   ```
5. Add a Gateway:

   ```shell
   cat <<TXT | tee gateway-test.yaml | k apply -f -
   apiVersion: gateway.networking.k8s.io/v1
   kind: Gateway
   metadata:
     name: prod-web
     namespace: gateway
   spec:
     gatewayClassName: nginx
     listeners:
     - protocol: HTTP
       port: 80
       name: prod-web-gw
       allowedRoutes:
         namespaces:
           from: Same
   TXT
   ```
6. Now make our HTTP routes so that we can incorporate our Gateway:
   ```shell
   cat <<TXT | k apply -f -
   apiVersion: gateway.networking.k8s.io/v1
   kind: HTTPRoute
   metadata:
     name: web-route
     namespace: gateway
   spec:
     parentRefs:
     - name: prod-web
     rules:
     - matches:
       - path:
           type: PathPrefix
           value: /
       backendRefs:
       - name: web-svc
         port: 8080
   TXT
   ```
7. Test it out:
   ```shell
   k -n gateway run --rm -it --image=busybox gw-tester -- sh
   # wget --spider --timeout=3 http://prod-web-gw/status.html
   ```
