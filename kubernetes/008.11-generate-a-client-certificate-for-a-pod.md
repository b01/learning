# Generate A Client Certificate for A Pod

**Client Certificates**

* NOT automatically mounted
* Must be manually created
* Best for system components or special workloads
* Expire and must be rotated manually unless using cert-manager

1. Create a private key

   ```shell
   openssl genrsa -out app.key 2048
   ```
2. Create a CSR

   ```shell
   openssl req -new -key app.key -out app.csr -subj "/CN=myapp/O=mygroup"
   ```
3. Sign it with the Kubernetes CA
   You need access to:
   * /etc/kubernetes/pki/ca.crt
   * /etc/kubernetes/pki/ca.key

   Then:

   ```shell
   sudo openssl x509 -req -in app.csr \
       -CA /etc/kubernetes/pki/ca.crt -CAkey /etc/kubernetes/pki/ca.key -CAcreateserial \
       -out app.crt -days 365
   ```
4. Store the cert + key in a Secret

   ```shell
   kubectl create secret generic app-cert \
   --from-file=app.crt \
   --from-file=app.key
   ```
5. Mount the Secret into the Pod
   ```yaml
   spec:
     volumes:
     - name: certs
       secret:
       secretName: app-cert
    containers:
    - name: metrics-server
      image: metrics-server:0.8.1
      volumeMounts:
      - name: certs
        mountPath: /etc/certs
   ```
6. Configure your client to use TLS
   Your app must use:
   ```yaml
   spec:
     containers:
     - name: metrics-server
       image: metrics-server:0.8.1
       volumeMounts:
       - name: certs
         mountPath: /etc/certs
         args:
         - --client-certificate=/etc/certs/app.crt
         - --client-key=/etc/certs/app.key
         - --certificate-authority=/var/run/secrets/kubernetes.io/serviceaccount/ca.crt
   ```
