# Configure Networking

Before we begin, lets see what bridge networks we have so far:
`sudo bridge link show`. Just make a mental note, or paste the output for
reference later.

1. Fill in the values for the `kube-proxy` config and then apply the manifest.
   ```shell
   cd ~/manifests
   getIps () {
      iface=${1}
      export IPV4=$(ip -4 addr show scope global dev ${iface} | grep "inet\b" | awk '{print $2}' | cut -d/ -f1)
      export IPV6=$(ip -6 addr show scope global dev ${iface} | grep "inet6\b" | awk '{print $2}' | cut -d/ -f1)
   }
   getIps "enp0s8"
   export POD_CIDRS=fd12:3456:789a:1000::/56,10.244.0.0/16
   export KUBE_VER=v1.35
   cat /vagrant/kube-proxy.yaml.tmpl | envsubst | tee kube-proxy.yaml
   kubectl apply -f kube-proxy.yaml
   ```
2. Install Helm
   ```shell
   HELM_VER=4.1.4
   wget https://get.helm.sh/helm-v${HELM_VER}-linux-amd64.tar.gz
   sudo tar Czxvf /usr/local/bin/ helm-v${HELM_VER}-linux-amd64.tar.gz --strip-components=1
   ```
3. Install CoreDNS using the [CoreDNS Helm chart].
   ```shell
   helm repo add coredns https://coredns.github.io/helm
   helm repo update
   helm --namespace=kube-system install coredns coredns/coredns -f /vagrant/coredns-values.yaml
   ```
