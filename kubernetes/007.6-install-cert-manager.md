# Install Cert-Manager

`cert-manager` adds certificates and certificate issuers as resource types,
and simplifies the process of obtaining, renewing and using those certificates.

It supports issuing certificates from a variety of sources, but for practice,
well focus on local in-cluster issuance.

It also attempts to renew certificates at an appropriate time before expiry to
reduce the risk of outages and remove toil.

```shell
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.20.2/cert-manager.yaml
```

## Test Issuing Certificate

Let test making a Certificate Authority (self-signed), issue a certificate for
an application, then integrate it into the application.
1. Make a self-signed CA

   ```shell
   cat <<TXT | tee self-signed-ca.yaml | kubectl apply -f -
   apiVersion: v1
   kind: Namespace
   metadata:
     name: cert-test
   ---
   apiVersion: cert-manager.io/v1
   kind: Issuer
   metadata:
     name: ca-self-signed-issuer
     namespace: cert-test
   spec:
     selfSigned: {}
   ---
   apiVersion: cert-manager.io/v1
   kind: Certificate
   metadata:
     name: cert-ca
     namespace: cert-test
   spec:
     isCA: true
     commonName: acme
     secretName: acme-ca
     privateKey:
       algorithm: RSA
       size: 2048
     issuerRef:
       name: ca-self-signed-issuer
       kind: Issuer
       group: cert-manager.io
   ---
   apiVersion: cert-manager.io/v1
   kind: Issuer
   metadata:
     name: acme-ca-issuer
     namespace: cert-test
   spec:
     ca:
       secretName: acme-ca
   TXT
   ```

   NOTE: This is called [Bootstrapping CA Issuers], and only needs to be done
   when you plan to manage your own PKI in-cluster.

   ```shell
   kubectl apply -f - <<TXT
   apiVersion: cert-manager.io/v1
   kind: Certificate
   metadata:
     name: web-app-crt
     namespace: cert-test
   spec:
     secretName: web-app-crt
     usages:
     - digital signature
     - key encipherment
     dnsNames:
     - web-app-svc.cert-test
     issuerRef:
       name: acme-ca-issuer
   TXT
   ```
