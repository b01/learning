# Guide: Pod Service Account

There is ServiceAccount `secret-reader` in Namespace `project-swan`. We'll make
a Pod with image `nginx:1-alpine` named `api-contact` which uses this
ServiceAccount.

Then we'll `kubectl exec` into the Pod and use `curl` to manually query all
Secrets from the Kubernetes API and write the result into file
`/tmp/answers/cluster-secrets.json`.

## Get Started

1. Generate a Pod manifest using `kubectl`:

   ```shell
   kubectl -n project-swan --dry-run=client -o yaml run --image=nginx:1-alpine api-contact | tee pod-secret-service.yaml
   ```
  
2. Edit the Pod manifest to use the `serviceAccountName: secret-reader`. Also
   add a volume mount for the Kubernetes CA certificate; it is needed to
   query the cluster as we'll soon see.

   ```yaml
   apiVersion: v1
   kind: Pod
   metadata:
     labels:
       run: api-contact
     name: api-contact
     namespace: project-swan
   spec:
     containers:
     - image: nginx:1-alpine
       name: api-contact
       volumeMounts:                            # add
       - name: cacert                           # add
         mountPath: /etc/kubernetes/pki/ca.crt  # add
     serviceAccountName: secret-reader          # add
     volumes:                                   # add
     - hostPath:                                # add
        path: /etc/kubernetes/pki/ca.crt        # add
       name: cacert                             # add
   ```
3. Execute into the Pod

   ```shell
   kubectl exec -it -n project-swan api-contact -- sh
   ```
4. Now that we have logged into the Pod, we can attempt to query the Kubernetes
   API for the secrets.

   ```shell
   TOKEN=$(cat /var/run/secrets/kubernetes.io/serviceaccount/token)
   curl -X GET --header="Authorization: Bearer ${TOKEN}" \
       --cacert=/etc/kubernetes/pki/ca.crt \
       https://[2000:192:168:56::11]:6443/api/v1/namespaces/project-swan/secrets
   ```

   NOTE: We need the Kubernetes CA certificate to allow the TLS connection
   to work, otherwise we would have to disable TLS, which is NOT good practice.
