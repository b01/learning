# Make A Sidecar

In the namespace `log` well make a deployment `worker` that runs on the script:


1. Generate a new deployment to modify:

   ```shell
   kubectl -n log --dry-run=client -o yaml create deployment worker --image=busybox
   ```
2. Modify it to add a command to the container to keep it running:
   ```shell
   spec:
      containers:
        - image: busybox
          name: busybox
          command:
            - sh
            - -c
            - |
              mkdir /var/log
              shutd () {
                  printf "%s" "Shutting down the container gracefully..."
                  KEEP_RUNNING="0"
              }
              trap 'shutd' TERM
              KEEP_RUNNING=1
              while [ "${KEEP_RUNNING}" != "0" ]
              do
                  echo "doing stuff" >> /var/log/worker.log
                  sleep 1
              done
              exit 0
   ```

   NOTE: The command uses YAML `|` convention to add the script inline. It's a
   nice tip.
3. For giggles, we'll make a sidecar that tails the logfile from another
   container that you
modify except the volume mounts.
```yaml
spec:
  containers:
  - name: worker
    # ...
    volumeMounts:
    - mountPath: /var/log
      name: log-data
  - name: sidecar
    image: busybox
    volumeMounts:
    - name: log-data
      mountPath: /var/log/worker.log
  volumes:
   - emptyDir: {}
     name: log-data
```
