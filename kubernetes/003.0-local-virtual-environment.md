# Local Virtual Environment

Time to spin-up a local virtual environment. This environment will consist of
3 virtual machines. 1 control-plane and 2 worker nodes. The following are bare
minimum requirements.

1. Enable virtualization in your BIOS.
2. Install [VirtualBox]
3. Install [Vagrant]
4. Computer requirements:
   1. At least 6GB of RAM (2 GB per machine).
   2. At least 3 CPU cores (1 per machine).

By making sure all the initial software and network configurations are in
place. This prepares the machines to either serve as a control plane or worker
node.
