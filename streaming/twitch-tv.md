# Twitch TV

All about streaming on Twitch.tv.

## Bits

"Bits are a virtual good you can buy on Twitch that give you the power to
encourage and show support for streamers, get attention in chat through
animated Cheermotes, Power-ups, get recognition through badges, leaderboards,
with even more possibilities in Extensions."

"A Cheer is a chat message that uses Bits. Bits can be used one by one, all at
once, or anything in between. Using many Bits at once shows more support
through cool animations called Cheermotes. You can pin your message so it
stays visible in chat."

**Cheer** - A chat message enhanced by using `Bits`. The more `Bits` poured in
the more the better the `Cheermote` can be. You can even "pin" your message
to the point where it stays visible. Sound like this can be abused by the wrong
viewer.
