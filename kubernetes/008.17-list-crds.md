# Guide: List CRDs

We'll get a list of CRDs for `cert-manager` and store them in a YAML file using
`kubectl`'s standard output into the file `/tmp/answers/cert-manager-crds.yaml`.

1. List the current CRDs:

   ```shell
   kubectl get crds -l app.kubernetes.io/instance=cert-manager
   ```
2. Now list all the CRDs as YAML into a file
   ```shell
   kubectl get crds -l app.kubernetes.io/instance=cert-manager -o yaml \
       > /tmp/answers/cert-manager-crds.yaml
   ```

   NOTE: The YAML that is output is an array of all the CRDs. So this YAML file
   could also be applied.
