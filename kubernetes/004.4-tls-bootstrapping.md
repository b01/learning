# TLS bootstrapping

This process allows a `kubelet` authorization to authenticate with the
`kube-apiserver` then generate a long-term TLS certificate for itself.
It will also renew that certificate when its expiration time is near.

For more details see [TLS bootstrapping] and [Authenticating with Bootstrap
Tokens].

1. Initial bootstrap authentication can be done with one of the following:
   1. Generate a Bootstrap token:
      ```shell
      TOKEN_ID=$(openssl rand -base64 10 | tr -dc 'a-z0-9' | head -c 6)
      TOKEN_SECRET=$(openssl rand -base64 10 | tr -dc 'a-z0-9' | head -c 16)
      cat <<TXT | envsubst | tee bootstrap-token.yaml | k apply -f -
      apiVersion: v1
      kind: Secret
      metadata:
        name: bootstrap-token-${TOKEN_ID}
        namespace: kube-system
      type: bootstrap.kubernetes.io/token
      stringData:
        description: "The default bootstrap token generated manually."
        auth-extra-groups: system:bootstrappers:worker,system:bootstrappers:ingress
        token-id: "${TOKEN_ID}"
        token-secret: "${TOKEN_SECRET}"
        # Allowed usages.
        usage-bootstrap-authentication: "true"
        usage-bootstrap-signing: "true"
      TXT
      ```

      NOTE: The type of the secret must be `bootstrap.kubernetes.io/token` and
      the name must be `bootstrap-token-<token id>`. It must also exist in the
      `kube-system` namespace. Bootstrap Tokens must match the regular
      expression `[a-z0-9]{6}\.[a-z0-9]{16}`.
   2. Alternatively, generate a Token authentication file:

      ```shell
      export BOOTSTRAP_TOKEN="$(head -c 16 /dev/urandom | od -An -t x | tr -d ' ')"
      cat <<TXT | sudo tee /etc/kubernetes/bootstrap-token
      ${BOOTSTRAP_TOKEN},kubelet-bootstrap,10001,"system:bootstrappers"
      TXT
      ```
2. Ensure the `kube-apiserver` option `--enable-bootstrap-token-auth=true` or
   `--token-auth-file=/etc/kubernetes/bootstrap-token` is set in the
   `kube-apiserver.yaml` manifest.

   NOTE: We do this in the next section.
3. Enable bootstrapping nodes to make a CSR by adding this `ClusterRoleBinding`
   on the `control-plane-01`.

   ```shell
   cat <<TXT | k apply -f -
   apiVersion: rbac.authorization.k8s.io/v1
   kind: ClusterRoleBinding
   metadata:
     name: create-csrs-for-bootstrapping
   subjects:
   - kind: Group
     name: system:bootstrappers
     apiGroup: rbac.authorization.k8s.io
   roleRef:
     kind: ClusterRole
     name: system:node-bootstrapper
     apiGroup: rbac.authorization.k8s.io
   TXT
   ```
4. Configure the `controller-manager` so that it auto-approves all CSRs for
   the group `system:bootstrappers`.

   ```shell
   cat <<TXT | k apply -f -
   # Approve all CSRs for the group "system:bootstrappers"
   apiVersion: rbac.authorization.k8s.io/v1
   kind: ClusterRoleBinding
   metadata:
     name: auto-approve-csrs-for-group
   subjects:
   - kind: Group
     name: system:bootstrappers
     apiGroup: rbac.authorization.k8s.io
   roleRef:
     kind: ClusterRole
     name: system:certificates.k8s.io:certificatesigningrequests:nodeclient
     apiGroup: rbac.authorization.k8s.io
   TXT
   ```
5. To enable the `kubelet` to renew its own client certificate, make a
   ClusterRoleBinding:

   ```yaml
   # Approve renewal CSRs for the group "system:nodes"
   apiVersion: rbac.authorization.k8s.io/v1
   kind: ClusterRoleBinding
   metadata:
     name: auto-approve-renewals-for-nodes
   subjects:
   - kind: Group
     name: system:nodes
     apiGroup: rbac.authorization.k8s.io
   roleRef:
     kind: ClusterRole
     name: system:certificates.k8s.io:certificatesigningrequests:selfnodeclient
     apiGroup: rbac.authorization.k8s.io
   ```
6. Generate a bootstrap kubeconfig for all `kubelet`s to use:

   ```shell
   kubectl config set-cluster bootstrap \
     --server='https://192.168.56.11:6443' \
     --certificate-authority=/etc/kubernetes/pki/ca.crt \
     --kubeconfig=/etc/kubernetes/bootstrap-kubelet.conf

   kubectl config set-credentials kubelet-bootstrap \
     --token=${BOOTSTRAP_TOKEN} \
     --kubeconfig=/etc/kubernetes/bootstrap-kubelet.conf

   kubectl config set-context bootstrap \
     --user=kubelet-bootstrap \
     --cluster=bootstrap \
     --kubeconfig=/etc/kubernetes/bootstrap-kubelet.conf

   kubectl config use-context bootstrap \
     --kubeconfig=/etc/kubernetes/bootstrap-kubelet.conf
   ```
