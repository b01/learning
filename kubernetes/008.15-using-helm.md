# Guide: Using Helm

Visit [Nginx Helm chart] for more details.

1. Add the Bitnami repository
   ```shell
   helm repo add bitnami https://charts.bitnami.com/bitnami
   ```
2. Update the repo:
   ```shell
   helm repo update bitnami
   ```
3. Install the nginx chart or use `helm template` to generate a manifest you
   can apply:
   ```shell
   helm install web-release bitnami/nginx --version 25.0.2 --set="replicaCount=2" --set="service.type=NodePort"

   helm template --dry-run=client web-release bitnami/nginx --namespace=helm-test --version=25.0.2 --set="replicaCount=2" --set="service.type=NodePort"
   ```

## ArgoCD

This is another example of using helm to generate a template for ArgoCD.

```shell
helm repo add argo https://argoproj.github.io/argo-helm
helm repo update

helm template argo-cd argo/argo-cd \
  --version=7.7.1 \
  --namespace=argocd \
  --set="crds.install=false" \
  | tee argo-cd-manifests.yaml
```
